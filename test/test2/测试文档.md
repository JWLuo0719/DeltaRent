## 三、发现的Bug

### Bug 1：找回密码显示成功但实际未生效 🔴 高优先级

| 项目 | 内容 |
|------|------|
| 问题描述 | 找回密码流程完成后提示"密码重置成功"，但实际密码未修改，仍可使用原密码登录 |
| 复现步骤 | 1. 点击"忘记密码" → 2. 输入手机号获取验证码 → 3. 输入新密码确认 → 4. 提示成功 → 5. 用新密码登录失败，原密码仍有效 |
| 预期行为 | 密码重置成功后，新密码生效，原密码失效 |
| 严重程度 | 🔴 高 |

---

### Bug 2：修改密码时新旧密码相同会弹回登录页 🟡 中优先级

| 项目 | 内容 |
|------|------|
| 问题描述 | 在个人资料页修改密码时，输入的新密码与原密码相同，系统无提示直接弹回登录页 |
| 复现步骤 | 1. 登录进入个人资料页 → 2. 修改密码 → 3. 原密码正确，新密码与原密码相同 → 4. 点击确认 → 5. 直接跳转登录页 |
| 预期行为 | 前端或后端校验，提示"新密码不能与原密码相同" |
| 严重程度 | 🟡 中 |

---

### Bug 3：按装备等级筛选功能未生效 🟡 中优先级

| 项目 | 内容 |
|------|------|
| 问题描述 | 在账号租赁大厅（`/rentals`）中，按装备等级进行筛选时，系统提示"暂无可租账号"，但实际上存在符合该等级的账号，筛选功能未正确生效 |
| 复现步骤 | 1. 登录后访问账号租赁大厅 → 2. 点击"装备等级"筛选 → 3. 选择某个等级 → 4. 系统显示"暂无可租账号" |
| 预期行为 | 正确筛选并显示符合该装备等级的账号列表 |
| 严重程度 | 🟡 中 |

**对应截图**：`rental-filter-by-level-failed.png`
