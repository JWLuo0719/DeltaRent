# DeltaRent 后端接口文档

本文档基于当前仓库中的真实前后端实现整理，作为联调与后续扩展的统一契约。除特别说明外，接口前缀均为 `/api`。

## 1. 通用约定

### 1.1 统一响应格式

```ts
interface ApiResponse<T> {
  success: boolean;
  message: string;
  data: T;
}
```

### 1.2 认证方式

- 需要登录的接口通过 `Authorization: Bearer <token>` 传递 JWT
- JWT 中包含 `userId`、`username`、`role`、`pwdUpdatedAt`
- 当用户修改密码或重置密码后，旧 token 会自动失效

### 1.3 角色说明

- `ADMIN`：管理员
- `CS`：客服
- `USER`：普通用户

## 2. 认证模块

### 2.1 登录

`POST /api/auth/login`

请求体：

```json
{
  "phone": "13800138000",
  "password": "123456"
}
```

兼容字段：

- 支持 `phone`
- 兼容旧字段 `username`

成功响应：

```json
{
  "success": true,
  "message": "登录成功",
  "data": {
    "token": "jwt-token",
    "user": {
      "id": 1,
      "username": "13800138000",
      "displayName": "演示用户",
      "phone": "13800138000",
      "role": "USER"
    }
  }
}
```

失败示例：

```json
{
  "success": false,
  "message": "手机号或密码错误",
  "data": null
}
```

### 2.2 注册

`POST /api/auth/register`

请求体：

```json
{
  "phone": "13800138000",
  "password": "123456",
  "nickname": "测试用户"
}
```

说明：

- `phone` 必须匹配 `^1[3-9]\\d{9}$`
- `password` 最少 6 位
- 默认分配 `USER` 角色
- `username` 若未传入，则默认等于手机号

成功响应：

```json
{
  "success": true,
  "message": "注册成功",
  "data": null
}
```

### 2.3 发送验证码

`POST /api/auth/send-verify-code`

请求体：

```json
{
  "phone": "13800138000",
  "type": "reset_password"
}
```

`type` 支持：

- `reset_password`
- `register`
- `login`

业务规则：

- 验证手机号格式
- 同一手机号 60 秒内不可重复发送
- 验证码为 6 位数字
- 有效期 10 分钟
- 当前为开发联调环境，短信为模拟发送，验证码会记录到数据库并打印日志
- `reset_password`、`login` 要求手机号已注册
- `register` 要求手机号未注册

成功响应：

```json
{
  "success": true,
  "message": "验证码已发送",
  "data": null
}
```

### 2.4 重置密码

`POST /api/auth/reset-password`

请求体：

```json
{
  "phone": "13800138000",
  "verifyCode": "123456",
  "newPassword": "newPassword123"
}
```

业务规则：

- 仅校验该手机号最近一次 `reset_password` 验证码
- 验证码必须未过期、未使用、且内容匹配
- 重置成功后验证码标记为已使用
- 重置成功后原有 token 自动失效

成功响应：

```json
{
  "success": true,
  "message": "密码重置成功",
  "data": null
}
```

## 4. 门户与租赁商品

### 4.1 门户摘要

`GET /api/portal/summary`

返回首页使用的标题、指标、模块和公告数据。

### 4.2 租赁账号列表

`GET /api/rentals`

查询参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `keyword` | string | 模糊匹配 `name` / `category` / `tagText` / `equipmentLevelText` |
| `tags` | string | 多标签，英文逗号分隔 |
| `level` | string | `Basic` / `Mid` / `Advanced` / `Full` |
| `status` | string | `AVAILABLE` / `RENTED` / `MAINTENANCE` |
| `sortBy` | string | `default` / `price_asc` / `price_desc` |
| `page` | number | 页码，默认 `1` |
| `pageSize` | number | 每页条数，默认 `12` |

`level` 规则：

- `Basic`：匹配“新手 / 基础”
- `Mid`：匹配“进阶 / 中阶”
- `Advanced`：匹配“高阶 / 毕业”
- `Full`：匹配“满配 / 顶级 / 毕业装 / 六套”

成功响应：

```json
{
  "success": true,
  "message": "ok",
  "data": {
    "list": [
      {
        "id": 1001,
        "name": "高战账号 A01",
        "category": "premium",
        "tagText": "满配仓库,稀有外观",
        "hourPrice": 28,
        "coinAmountText": "1200万哈夫币",
        "equipmentLevelText": "六套毕业装",
        "warehouseValueText": "高价值仓库",
        "status": "AVAILABLE",
        "description": "顶级作战账号，仓库满配，适合高强度对局。",
        "isHot": true,
        "tag": "满配仓库,稀有外观",
        "price": "28 / 小时",
        "coinAmount": "1200万哈夫币",
        "equipmentLevel": "六套毕业装",
        "warehouseValue": "高价值仓库"
      }
    ],
    "total": 20,
    "allTags": ["满配仓库", "稀有外观", "活动道具", "新手试用"]
  }
}
```

说明：

- `list` 为当前页数据
- `total` 为分页前总数
- `allTags` 为全量账号聚合出的标签集合，供前端筛选器使用

### 4.3 租赁账号详情

`GET /api/rentals/{id}`

返回单个账号详情，字段结构与列表项一致。

## 5. 订单模块

### 5.1 创建订单

`POST /api/orders`

请求体：

```json
{
  "accountId": 1001,
  "rentHours": 6,
  "contactInfo": "QQ: 123456",
  "remark": "希望下午 2 点交付"
}
```

业务规则：

- 仅登录用户可调用
- 账号必须存在且状态为 `AVAILABLE`
- 同一用户 + 同一账号在 `WAITING_CONFIRM` / `IN_PROGRESS` 状态下禁止重复提交
- 初始状态固定为 `WAITING_CONFIRM`
- 金额计算为 `hourPrice * rentHours`

成功响应：

```json
{
  "success": true,
  "message": "订单已提交",
  "data": {
    "orderNo": "DR1746240000000",
    "accountId": 1001,
    "rentHours": 6,
    "amount": 168.00,
    "status": "WAITING_CONFIRM",
    "estimatedDelivery": "5分钟内由客服确认"
  }
}
```

重复下单失败示例：

```json
{
  "success": false,
  "message": "该账号已有进行中的订单，请勿重复提交",
  "data": null
}
```

### 5.2 我的订单

### 5.3 订单详情

### 5.4 取消订单

### 5.5 后台订单列表
