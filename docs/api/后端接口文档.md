# DeltaRent 后端接口文档

> 本文档基于前端 `src/web/src/api/index.ts` 和 `src/web/src/types/api.ts` 生成，供后端开发参考。

## 通用说明

**Base URL**: `/api`

**统一响应格式**:
```typescript
interface ApiResponse<T> {
  success: boolean;
  message: string;
  data: T;
}
```

**认证方式**: `Authorization: Bearer <token>`（JWT）

**角色说明**: `ADMIN`（管理员）、`CS`（客服）、`USER`（普通用户）

---

## 一、认证 Auth

### 1.1 登录
```
POST /api/auth/login
```

**请求体**:
```json
{
  "phone": "13800138000",
  "password": "password123"
}
```

**成功响应**:
```json
{
  "success": true,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "displayName": "Admin Demo User",
      "role": "ADMIN"
    }
  }
}
```

**失败响应**:
```json
{
  "success": false,
  "message": "手机号或密码错误",
  "data": null
}
```

**业务逻辑**:
- 按 `phone` 查询用户（phone 有 UNIQUE 约束）
- 使用 BCrypt 验证密码
- 验证 `status = 1`（账号正常）
- 签发 JWT Token（包含 userId、role），建议有效期 7 天
- 失败返回 `success: false`

---

### 1.2 注册
```
POST /api/auth/register
```

**请求体**:
```json
{
  "phone": "13800138000",
  "password": "password123",
  "nickname": "测试用户"
}
```
- `nickname` 可选，不传则默认用手机号

**成功响应**:
```json
{
  "success": true,
  "message": "注册成功",
  "data": null
}
```

**业务逻辑**:
- 验证手机号格式（/^1[3-9]\d{9}$/）
- 验证手机号唯一性
- 验证密码至少6位
- 密码用 BCrypt 加密存储
- 自动分配默认角色 `USER`

---

### 1.3 发送验证码
```
POST /api/auth/send-verify-code
```

**请求体**:
```json
{
  "phone": "13800138000",
  "type": "reset_password"
}
```
- `type` 可选值: `reset_password` | `register` | `login`

**成功响应**:
```json
{
  "success": true,
  "message": "验证码已发送",
  "data": null
}
```

**业务逻辑**:
- 验证手机号格式
- 生成6位数字验证码
- 调用短信网关发送（生产环境需接入阿里云/腾讯云短信）
- 验证码有效期10分钟
- 同一手机号60秒内不可重复发送

---

### 1.4 重置密码
```
POST /api/auth/reset-password
```

**请求体**:
```json
{
  "phone": "13800138000",
  "verifyCode": "123456",
  "newPassword": "newPassword123"
}
```

**成功响应**:
```json
{
  "success": true,
  "message": "密码重置成功",
  "data": null
}
```

**业务逻辑**:
- 验证验证码正确性
- 验证验证码未过期
- 新密码用 BCrypt 加密存储
- 密码修改后使原有 token 失效

## 三、账号产品 Rental Products

### 3.1 账号列表（分页筛选）
```
GET /api/rentals
```

**Query 参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | string | 关键词，模糊匹配 name / tagText / equipmentLevelText |
| tags | string | 标签，多个用英文逗号分隔，如 `满配仓库,稀有外观` |
| level | string | 装备等级，如 `Basic` / `Mid` / `Advanced` / `Full` |
| status | string | 可租状态，`AVAILABLE` 或空（全部） |
| sortBy | string | 排序：`price_asc` / `price_desc` / `default` |
| page | number | 页码，默认 1 |
| pageSize | number | 每页条数，默认 12 |

**成功响应**:
```json
{
  "success": true,
  "message": "ok",
  "data": {
    "list": [
      {
        "id": 1001,
        "name": "高战账号 A01",
        "category": "premium",
        "tagText": "满配仓库,稀有外观",
        "hourPrice": 28,
        "coinAmountText": "1200万哈夫币",
        "equipmentLevelText": "六套毕业装",
        "warehouseValueText": "高价值仓库",
        "status": "AVAILABLE",
        "description": "顶级作战账号，仓库满配，稀有外观齐全...",
        "isHot": true
      }
    ],
    "total": 20,
    "allTags": ["满配仓库", "稀有外观", "活动道具", "新手试用"]
  }
}
```

**业务逻辑**:
- 支持多条件组合过滤
- 排序：price_asc（价格升序）、price_desc（价格降序）
- `allTags` 聚合所有账号的标签，用于筛选下拉框

## 四、订单 Orders

### 4.1 创建订单
```
POST /api/orders
```

**请求体**:
```json
{
  "accountId": 1001,
  "rentHours": 6,
  "contactInfo": "QQ: 123456",
  "remark": "希望下午2点交付"
}
```

**成功响应**:
```json
{
  "success": true,
  "message": "订单已提交",
  "data": {
    "orderNo": "DR20260423001",
    "accountId": 1001,
    "rentHours": 6,
    "status": "WAITING_CONFIRM",
    "estimatedDelivery": "5分钟内由客服确认"
  }
}
```

**失败响应（重复下单）**:
```json
{
  "success": false,
  "message": "该账号已有进行中的订单，请勿重复提交",
  "data": null
}
```

**业务逻辑**:
- 幂等校验：同一账号 + 同一用户 + 进行中订单 → 返回错误
- 验证账号存在且可租（`status = AVAILABLE`）
- 计算应付金额（单价 × 时长 × 折扣）
- 生成订单号（格式：`DR + 时间戳`）
- 初始状态 `WAITING_CONFIRM`

## 六、数据结构

### sys_user 表（用户）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| phone | varchar(20) | 手机号（NOT NULL + UNIQUE） |
| password_hash | varchar(255) | BCrypt 加密后的密码 |
| nickname | varchar(50) | 昵称 |
| status | tinyint | 状态（1=正常，0=禁用） |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### sms_verify_code 表（验证码）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| phone | varchar(20) | 手机号 |

| type | varchar(20) | 用途：reset_password / register / login |
| expire_time | datetime | 过期时间 |

### rental_product 表（账号产品）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |

| category | varchar(50) | 分类：premium / event / trial |
| tag_text | varchar(255) | 标签文字，逗号分隔 |
| hour_price | decimal(10,2) | 单价（元/小时） |

| description | text | 账号描述 |

### rental_order 表（订单）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| order_no | varchar(32) | 订单号（UNIQUE） |

| rent_hours | int | 租赁时长 |
| contact_info | varchar(100) | 联系方式 |

| status | varchar(30) | 订单状态 |

## 七、注意事项

1. **JWT Token**: 包含 userId、role 信息，有效期建议 7 天，所有需认证接口需验证
2. **RBAC**: 后端每个接口都要校验权限，角色枚举：`ADMIN(1)`、`USER(2)`、`CS(3)`
3. **密码安全**: 必须使用 BCrypt 或 Argon2 加密存储，禁止明文
4. **短信服务**: 生产环境需接入短信网关（阿里云/腾讯云）
5. **验证码安全**: 限制同一 IP/手机号的发送频率，防止滥用
6. **幂等校验**: `/api/orders` 需防止同一账号重复下单
7. **操作日志**: 用户角色变更、禁用启用等操作需记录日志
8. **跨域**: 允许 `Access-Control-Allow-Origin: *`
