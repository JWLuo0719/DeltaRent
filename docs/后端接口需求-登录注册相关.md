# 后端接口需求文档 - 登录注册模块

> 本文档描述前端已实现但后端尚未提供的接口需求，供后端开发参考。

## 一、已实现的前端接口（需后端实现）

### 1. 登录（手机号 + 密码）
- **接口**: `POST /api/auth/login`
- **前端路径**: `src/web/src/api/index.ts` -> `login()`
- **请求体**:
```json
{
  "phone": "13800138000",
  "password": "password123"
}
```
- **响应**:
```json
{
  "success": true,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "displayName": "Admin Demo User",
      "role": "ADMIN"
    }
  }
}
```
- **业务逻辑**:
  - 按 `phone` 查询用户（phone 有 UNIQUE 约束）
  - 使用 BCrypt 验证密码
  - 验证 `status = 1`（账号正常）
  - 签发 JWT Token（包含 userId、role）
  - 失败返回 `success: false`，message 说明原因

---

### 2. 注册（手机号 + 密码）
- **接口**: `POST /api/auth/register`
- **前端路径**: `src/web/src/api/index.ts` -> `register()`
- **请求体**:
```json
{
  "phone": "13800138000",
  "password": "password123",
  "nickname": "测试用户"    // 可选
}
```
- **响应**:
```json
{
  "success": true,
  "message": "注册成功",
  "data": null
}
```
- **业务逻辑**:
  - 验证手机号格式（/^1[3-9]\d{9}$/）
  - 验证手机号唯一性（phone 有 UNIQUE 约束）
  - 验证密码至少6位
  - 密码用 BCrypt 加密存储
  - 自动分配默认角色 USER

---

### 3. 发送验证码
- **接口**: `POST /api/auth/send-verify-code`
- **前端路径**: `src/web/src/api/index.ts` -> `sendVerifyCode()`
- **请求体**:
```json
{
  "phone": "13800138000",
  "type": "reset_password"  // 可选值: reset_password | register | login
}
```
- **响应**:
```json
{
  "success": true,
  "message": "验证码已发送",
  "data": null
}
```
- **业务逻辑**:
  - 验证手机号格式
  - 生成6位数字验证码
  - 调用短信网关发送（需配置短信API）
  - 验证码有效期10分钟
  - 同一手机号60秒内不可重复发送
  - 记录发送日志

---

### 4. 重置密码
- **接口**: `POST /api/auth/reset-password`
- **前端路径**: `src/web/src/api/index.ts` -> `resetPassword()`
- **请求体**:
```json
{
  "phone": "13800138000",
  "verifyCode": "123456",
  "newPassword": "newPassword123"
}
```
- **响应**:
```json
{
  "success": true,
  "message": "密码重置成功",
  "data": null
}
```
- **业务逻辑**:
  - 验证手机号格式
  - 验证验证码正确性
  - 验证验证码未过期
  - 新密码用 BCrypt 加密存储
  - 密码修改后使原有 token 失效

## 二、数据库表结构

### sys_user 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| phone | varchar(20) | 手机号（NOT NULL + UNIQUE） |
| password_hash | varchar(255) | BCrypt 加密后的密码 |
| nickname | varchar(50) | 昵称（可为空） |
| status | tinyint | 账号状态（1=正常） |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### sms_verify_code 表（新建）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| phone | varchar(20) | 手机号 |
| code | varchar(6) | 验证码 |
| type | varchar(20) | 用途类型：reset_password/register/login |
| expire_time | datetime | 过期时间 |
| created_at | datetime | 创建时间 |

## 四、注意事项

1. **登录凭证**: 以手机号（phone）为登录字段，phone 作为唯一标识
2. **JWT Token**: 建议包含 userId、role 信息，有效期建议 7 天
3. **RBAC**: 注册后默认分配 USER 角色，JWT 中携带 role 信息便于权限控制
4. **短信服务**: 生产环境需接入短信网关（如阿里云、腾讯云短信服务）
5. **验证码安全**: 限制同一 IP/手机号的发送频率，防止滥用
6. **密码安全**: 密码需使用 BCrypt 或 Argon2 加密存储
7. **sys_user_role 表**: 建议补充 `UNIQUE KEY (user_id, role_id)` 防重复分配
