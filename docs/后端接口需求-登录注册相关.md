# 后端接口需求文档 - 登录注册模块

> 本文档描述前端已实现但后端尚未提供的接口需求，供后端开发参考。

## 一、已实现的前端接口（需后端实现）

### 1. 登录
- **接口**: `POST /api/auth/login`
- **前端路径**: `src/web/src/api/index.ts` -> `login()`
- **请求体**:
```json
{
  "username": "testuser",
  "password": "password123"
}
```
- **响应**:
```json
{
  "success": true,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "username": "testuser",
      "displayName": "测试用户",
      "role": "user"
    }
  }
}
```

---

### 2. 注册
- **接口**: `POST /api/auth/register`
- **前端路径**: `src/web/src/api/index.ts` -> `register()`
- **请求体**:
```json
{
  "username": "testuser",
  "password": "password123",
  "nickname": "测试用户",    // 可选
  "phone": "13800138000"    // 可选
}
```
- **响应**:
```json
{
  "success": true,
  "message": "注册成功",
  "data": null
}
```
- **业务逻辑**:
  - 验证用户名不为空
  - 验证密码至少6位
  - 两次密码输入一致性校验（前端已做）
  - 用户名唯一性校验

---

### 3. 发送验证码
- **接口**: `POST /api/auth/send-verify-code`
- **前端路径**: `src/web/src/api/index.ts` -> `sendVerifyCode()`
- **请求体**:
```json
{
  "phone": "13800138000",
  "type": "reset_password"  // 可选值: reset_password | register | login
}
```
- **响应**:
```json
{
  "success": true,
  "message": "验证码已发送",
  "data": null
}
```
- **业务逻辑**:
  - 验证手机号格式（1开头的11位数字，前端已校验）
  - 生成6位数字验证码
  - 调用短信网关发送（需配置短信API）
  - 验证码有效期10分钟
  - 同一手机号60秒内不可重复发送
  - 记录发送日志

---

### 4. 重置密码
- **接口**: `POST /api/auth/reset-password`
- **前端路径**: `src/web/src/api/index.ts` -> `resetPassword()`
- **请求体**:
```json
{
  "phone": "13800138000",
  "verifyCode": "123456",
  "newPassword": "newPassword123"
}
```
- **响应**:
```json
{
  "success": true,
  "message": "密码重置成功",
  "data": null
}
```
- **业务逻辑**:
  - 验证手机号格式
  - 验证验证码正确性
  - 验证验证码未过期
  - 新密码加密存储（BCrypt或Argon2）
  - 密码修改后使原有token失效

## 二、数据库字段需求

|------|------|------|

## 四、注意事项

1. **短信服务**: 生产环境需接入短信网关（如阿里云、腾讯云短信服务）
2. **验证码安全**: 限制同一IP/手机号的发送频率，防止滥用
3. **密码安全**: 密码需使用BCrypt或 Argon2 加密存储
4. **日志记录**: 所有认证操作需记录操作日志便于审计
5. **Token生成**: 建议使用JWT，包含userId、username、role信息
