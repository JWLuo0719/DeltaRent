# DeltaRent 测试计划

## 一、概述

### 1.1 测试目的

本次测试旨在验证 DeltaRent（三角洲行动账号租赁管理系统）的功能完整性、系统稳定性和用户体验，确保系统达到可交付、可演示的标准。

### 1.2 测试范围

| 模块 | 测试内容 |
|------|----------|
| 注册模块 | 页面展示、手机号格式校验、密码校验、重复注册、注册成功 |
| 登录模块 | 页面展示、空表单校验、正确/错误密码登录、不同角色登录 |
| 首页模块 | 页面展示、导航跳转、热门账号、公告展示、联系客服、权限差异 |
| 租号大厅模块 | 页面展示、账号列表、分类筛选、高级筛选、搜索、排序、账号详情、下单流程 |
| 我要上架模块 | 页面展示、填写信息、提交上架、必填验证、重置功能 |
| 我的订单模块 | 订单列表、订单详情、取消订单、状态筛选、申请售后 |
| 个人中心模块 | 资料展示、修改昵称、修改密码、密码校验 |
| 管理员模块 | 登录、数据看板、用户管理、账号管理、订单管理、公告管理 |
| 游客模块 | 未登录访问首页、浏览账号、登录拦截 |
| 找回密码模块 | 弹窗展示、获取验证码、密码重置、新密码登录 |

### 1.3 测试目标

- 功能测试覆盖率 ≥ 95%
- 核心业务流程通过率 100%
- 发现并记录所有严重及以上级别Bug
- 所有已修复Bug验证通过

---

## 二、测试策略

### 2.1 测试类型

| 类型 | 说明 |
|------|------|
| 功能测试 | 验证各模块功能是否符合预期 |
| 流程测试 | 验证完整租赁业务流程是否通畅 |
| 校验测试 | 验证表单输入校验、错误提示 |
| 权限测试 | 验证不同角色的权限差异 |
| 回归测试 | 验证Bug修复后功能正常 |

### 2.2 测试方法

- 手动测试：执行测试用例，记录测试结果
- 探索性测试：发现未覆盖的边界情况
- 回归测试：修复后重新验证

### 2.3 通过标准

| 等级 | 标准 |
|------|------|
| 高优先级 | 必须100%通过 |
| 中优先级 | 通过率 ≥ 95% |
| 低优先级 | 通过率 ≥ 90% |

## 六、缺陷管理

### 6.1 缺陷等级

| 等级 | 说明 |
|------|------|
| 🔴 高 | 核心功能失效，阻塞测试 |
| 🟡 中 | 功能异常，影响用户体验 |
| 🟢 低 | 界面问题，建议优化 |

### 6.2 缺陷处理流程

1. 发现缺陷 → 记录Bug
2. 开发修复 → 标注修复状态
3. 回归测试 → 验证通过后关闭
