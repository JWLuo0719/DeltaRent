# DeltaRent 系统测试报告

## 一、测试概述

### 1.1 测试目的

本次测试旨在验证 DeltaRent（三角洲行动账号租赁管理系统）的核心功能是否正常运行，包括用户认证、账号租赁、订单管理、个人资料、后台管理、游客访问及找回密码等功能模块。

### 1.2 测试范围

| 模块 | 测试内容 |
|------|----------|
| 注册模块 | 注册页面展示、漏填校验、新用户注册、重复注册、密码一致性校验、手机号格式校验 |
| 登录模块 | 登录页面展示、空表单校验、正确/错误密码登录、不同角色登录 |
| 首页模块 | 首页展示、热门账号、导航跳转、公告展示、联系客服、角色权限差异 |
| 租号大厅模块 | 页面展示、账号列表、分类筛选、排序功能、高级筛选、搜索功能、账号详情、下单流程、防重复下单、租号须知 |
| 我要上架模块 | 上架页面展示、填写信息、提交上架、必填字段验证、重置功能、审核流程 |
| 我的订单模块 | 订单列表展示、订单详情、取消订单、状态筛选、申请售后 |
| 个人中心模块 | 资料展示、修改昵称、修改密码、密码校验 |
| 管理员模块 | 管理员登录、数据看板、用户管理、账号管理、订单管理、公告管理 |
| 游客模块 | 游客访问首页、浏览租号大厅、查看账号详情、登录拦截 |
| 找回密码模块 | 找回密码弹窗、获取验证码、密码重置、新密码登录验证 |
