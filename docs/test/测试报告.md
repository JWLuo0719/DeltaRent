# DeltaRent 系统测试报告

## 一、测试概述

### 1.1 测试目的

本次测试旨在验证 DeltaRent（三角洲行动账号租赁管理系统）的核心功能是否正常运行，包括用户认证、账号租赁、订单管理、个人资料、后台管理、游客访问及找回密码等功能模块。

### 1.2 测试范围

| 模块 | 测试内容 |
|------|----------|
| 注册模块 | 注册页面展示、漏填校验、新用户注册、重复注册、密码一致性校验 |
| 登录模块 | 登录页面展示、空表单校验、正确/错误密码登录 |
| 首页模块 | 首页展示、热门账号、导航跳转、公告展示、联系客服 |
| 租号大厅模块 | 页面展示、账号列表、分类筛选、装备等级筛选、状态筛选、价格筛选、高级筛选、排序功能、公告展示 |
| 订单模块 | 创建订单、账号选择、时长选择、折扣计算、防重复下单 |
| 我的订单模块 | 订单列表展示、取消订单、申请售后 |
| 个人资料模块 | 资料展示、修改昵称、重置功能、修改密码 |
| 管理员模块 | 管理员登录、后台管理、用户管理、角色管理、账号管理、订单管理、公告管理 |
| 游客模块 | 游客访问首页、浏览租号大厅、未登录拦截、登录后下单 |
| 找回密码模块 | 找回密码弹窗、获取验证码、密码重置、新密码登录验证 |

## 三、发现的Bug

### Bug 1：找回密码模块 - 验证码错误后计时暂停

| 项目 | 内容 |
|------|------|
| Bug编号 | BUG-001 |
| 严重程度 | 🟡 中 |
| 发现模块 | 找回密码模块 |
| 问题描述 | 输入错误验证码后，验证码按钮的计时会暂停，影响用户体验 |
| 预期结果 | 输入错误验证码后，验证码按钮计时应继续正常倒计时 |
| 实际结果 | 验证码按钮计时暂停 |
| 复现步骤 | 1. 点击"忘记密码"<br>2. 输入手机号获取验证码<br>3. 输入错误验证码<br>4. 观察验证码按钮计时状态 |
