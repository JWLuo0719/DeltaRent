## 一、项目概述

### 1. 项目背景

“三角洲行动”相关玩家群体围绕账号租赁、账号展示、订单咨询、售后申诉等场景，存在较高频的信息撮合需求。当前大量交易流程仍依赖微信群、QQ群、人工客服和零散表单完成，存在价格规则不透明、订单进度依赖人工同步、账号资源缺乏统一管理、售后记录难以沉淀等问题。本项目拟围绕这些核心能力，设计并实现一个面向课程实践的完整信息系统。

### 2. 系统目标

- 完成一个可运行、可演示、业务流程完整的信息系统原型
- 支持用户注册登录、账号浏览、订单提交、订单跟踪、后台审核、公告管理、数据统计等完整业务闭环
- 采用前后端分离架构，形成清晰的前台与后台边界

### 3. 开发环境

| 类别 | 技术选型 |
|------|----------|
| 前端 | Vue 3 + TypeScript + Vite + Element Plus |
| 后端 | Spring Boot 3 + Spring Security + JWT + MyBatis-Plus |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis |
| 版本管理 | Git + GitHub |

## 二、需求分析

### 1. 功能需求

#### 用户端功能

| 模块 | 功能 |
|------|------|
| 注册登录 | 手机号注册、登录、找回密码 |
| 账号大厅 | 查看账号列表、按名称搜索、标签筛选 |
| 账号详情 | 查看装备等级、仓库价值、租赁说明 |
| 租赁下单 | 选择时长、填写联系方式、提交订单 |
| 订单管理 | 查看订单列表、按状态筛选 |
| 个人中心 | 修改资料、修改密码 |

#### 管理员端功能

| 模块 | 功能 |
|------|------|
| 后台看板 | 查看订单统计、用户统计 |
| 账号管理 | 账号上下架、信息维护（中期阶段功能未完全实现） |
| 订单审核 | 订单确认、状态变更（中期阶段功能未完全实现） |

#### 主要业务流程

用户注册/登录 → 浏览账号列表 → 查看账号详情 → 选择租赁时长 → 提交订单 → 等待客服确认 → 账号交付

### 2. 非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 页面加载时间 < 3秒 |
| 安全 | 密码加密存储（BCrypt），手机号登录验证 |
| 兼容性 | 支持 Chrome、Edge 等主流浏览器 |
