# 账号列表页面（RentalListView）优化方案

## 一、现状与目标

### 现状
当前页面为"接口联调演示页"，仅有基础表格展示，距离计划书要求的"商品展示 + 账号详情 + 租赁下单"完整业务闭环差距较大。

### 优化目标
将页面从"表格展示"升级为"账号商品展示系统"，支持：账号浏览 → 详情查看 → 规格选择 → 下单租赁的完整用户路径。

---

- 实时价格计算（单价 × 时长）
- 联系方式 / 注意事项
- "立即下单"主按钮

## 三、功能模块详细设计

### 3.1 账号卡片

每个卡片包含：

```
┌──────────────────────────────────┐
│  [可租] [热门]    ← 状态标签     │
│                                  │
│  账号名称（大字）                  │
│  装备等级 | 仓库价值 | 哈夫币     │
│  ← 属性行，灰色小字               │
│                                  │
│  ¥XX /小时          [查看详情]   │
│  ← 价格 + 操作按钮                │
└──────────────────────────────────┘
```

卡片状态映射：

| status | 标签文字 | 标签颜色 | 可租用 |
|---|---|---|---|
| `AVAILABLE` | 可租 | 绿色 | 是 |
| `RENTED` | 已租出 | 黄色 | 否（禁用按钮） |
| `MAINTENANCE` | 维护中 | 灰色 | 否 |

### 3.2 筛选工具栏

| 筛选项 | 类型 | 说明 |
|---|---|---|
| 标签筛选 | 多选下拉（el-select multiple） | 按 `tag` 字段分组，支持多选 |
| 装备等级 | 单选下拉 | 如：入门 / 中级 / 高级 / 满配 |
| 价格区间 | 双滑块（el-slider range） | 最低价 ~ 最高价，单位元/小时 |
| 可租状态 | 单选开关 | 全部 / 仅可租 |
| 关键词搜索 | 输入框 | 匹配 name / tag / equipmentLevel |
| 排序 | 下拉 | 默认排序 / 价格升序 / 价格降序 / 装备等级 |

### 3.3 账号详情抽屉

```
┌────────────────────────────────┐
│  账号详情                    ✕ │
├────────────────────────────────┤
│  [图片1] [图片2] [图片3] ← 轮播│
│                                │
│  账号名称                      │
│  [可租] [入门级] ← 标签        │
│                                │
│  ── 账号资源 ──               │
│  装备等级：高级               │
│  仓库价值：120000             │
│  哈夫币：50000                │
│                                │
│  ── 选择租赁时长 ──           │
│  [1h] [6h] [12h] [24h]        │
│  ← 价格卡片，选中高亮          │
│                                │
│  应付金额：¥48                │
│  ← 动态计算，选中时长后刷新    │
│                                │
│  [立即下单（需登录）]          │
│  ← 登录状态显示不同按钮文案    │
│                                │
│  ⚠️ 注意事项：                │
│  1. 租用期间请勿修改密码       │
│  2. 按时长计费，提前归还不退   │
└────────────────────────────────┘
```

**动态价格计算逻辑**（前端估算，后端最终确认）：
- 基准单价：后端返回的 `price`（元/小时）
- 不同时长折扣：6h 9折，12h 8折，24h 7折（规则可配置化）
- 应付金额 = 单价 × 时长 × 折扣

### 3.4 登录跳转记忆

流程：
1. 用户未登录，点击"立即下单"
2. 跳转登录页，URL 携带 `redirect=/orders/create?accountId=xxx`
3. 登录成功后跳回下单页，自动带入账号 ID

## 四、视觉与主题适配

### 4.1 深色卡片网格

```
.product-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;

```

- 卡片背景：`rgba(255,255,255,0.04)` + 蓝色边框
- 悬浮效果：`translateY(-4px)` + 发光阴影
- 选中态：边框变亮 + 缩放 1.02

### 4.2 工具栏深色覆盖

对 `el-input`、`el-select`、`el-button` 均加 `:deep` 样式覆盖：
- 输入框：深色背景 `#1e293b`，白色文字，边框 `rgba(96,165,250,0.2)`
- 下拉框：与输入框一致
- 主按钮：复用 PortalView 的蓝色渐变风格

### 4.3 骨架屏与空状态

加载时：3×3 网格骨架屏（与 PortalView 一致的 `.sk-pulse` 动画）

空状态：
```

│    当前没有符合条件的账号            │
│    [清除筛选]                        │

```

## 五、分页与性能

| 优化项 | 实现方式 |
|---|---|
| 后端分页 | 接口参数加 `page` + `pageSize`，返回 `{ data, total }` |
| 前端分页组件 | `el-pagination`，支持切换页码和每页条数 |
| 骨架屏防 CLS | 数据加载前渲染 9 个骨架卡 |
| 关键词防抖 | `debounce` 300ms，避免每次输入都调接口 |

## 七、接口调整建议

### 7.1 `GET /api/rentals` 参数更新

```typescript
// 请求参数（query string）
interface RentalsParams {
  page?: number;        // 页码，默认 1
  pageSize?: number;     // 每页条数，默认 12
  keyword?: string;      // 关键词，匹配 name / tagText / equipmentLevelText
  tags?: string;        // 标签，多个用英文逗号分隔，如 "满配仓库,稀有外观"
  level?: string;       // 装备等级，如 "Basic" / "Mid" / "Advanced" / "Full"
  status?: string;       // 可租状态，"AVAILABLE" 或空（全部）
  sortBy?: string;       // 排序："price_asc" / "price_desc" / "default"
}
```

### 7.2 `GET /api/rentals` 响应格式（新增分页）

```typescript
// 旧格式（直接返回数组）
ApiResponse<RentalProduct[]>

// 新格式（分页 + 聚合标签）
ApiResponse<{
  list: RentalProduct[];   // 当前页账号列表
  total: number;           // 符合条件的总数量
  allTags: string[];       // 所有可用标签（用于筛选下拉）
}>
```

### 7.3 后端 Mock 更新（scripts/mock-server.mjs）

```javascript
// GET /api/rentals 需要支持以下查询参数过滤
// keyword: 模糊匹配 name
// tags: 逗号分隔，匹配 tagText
// level: 匹配 equipmentLevelText
// status: 匹配 status 字段
// sortBy: price_asc / price_desc
// page, pageSize: 分页

// 响应需返回 { list, total, allTags } 格式
```

### 7.4 `GET /api/rentals/:id` 账号详情接口（新增）

返回账号完整信息，包含资源详情和可选时长列表。
